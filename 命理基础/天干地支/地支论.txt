【地支三合局】

三合聚气，力量强大：

  申 子 辰 → 水局（北方水）
  寅 午 戌 → 火局（南方火）
  亥 卯 未 → 木局（东方木）
  巳 酉 丑 → 金局（西方金）

半合（两字相合，力量减半）：
  申子、子辰、申辰
  寅午、午戌、寅戌
  亥卯、卯未、亥未
  巳酉、酉丑、巳丑

────────────────────────────────────────────────────────
【地支三会方】

同方汇聚，比三合更纯粹：

  寅 卯 辰 → 东方木局
  巳 午 未 → 南方火局
  申 酉 戌 → 西方金局
  亥 子 丑 → 北方水局

────────────────────────────────────────────────────────
【地支六合】

  子 + 丑 = 土（子丑合土）
  寅 + 亥 = 木（寅亥合木）
  卯 + 戌 = 火（卯戌合火）
  辰 + 酉 = 金（辰酉合金）
  巳 + 申 = 水（巳申合水）
  午 + 未 = 土（午未合土，不化）

────────────────────────────────────────────────────────
【地支六冲】

  子 ↔ 午（水火冲）
  丑 ↔ 未（土土冲）
  寅 ↔ 申（木金冲）
  卯 ↔ 酉（木金冲）
  辰 ↔ 戌（土土冲）
  巳 ↔ 亥（火水冲）

  冲的影响：
    · 动荡、变化、分离、移动
    · 冲开库（辰戌丑未）则库中藏干透出
    · 日支被冲：婚姻感情不稳
    · 年支被冲：祖业难守、背井离乡

────────────────────────────────────────────────────────
【地支六害】

  子 ↔ 未（穿害）
  丑 ↔ 午（官符害）
  寅 ↔ 巳（刑害）
  卯 ↔ 辰（怨嗔害）
  申 ↔ 亥（害）
  酉 ↔ 戌（害）

  害的影响较冲为轻，多主阴暗之事，背后是非

────────────────────────────────────────────────────────
【地支三刑】

恃势之刑（寅 → 巳 → 申 → 寅，互刑）：
  寅刑巳，巳刑申，申刑寅

无恩之刑（丑 → 戌 → 未 → 丑，互刑）：
  丑刑戌，戌刑未，未刑丑

无礼之刑：子刑卯，卯刑子（相互）

自刑：辰辰、午午、酉酉、亥亥（同支相见）

  刑的影响：
    · 主官司、手术、刑罚、疾病
    · 刑中带贵（驿马、贵人）则反主显达
