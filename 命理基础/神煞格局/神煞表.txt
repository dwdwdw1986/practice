【吉神】

▶ 天乙贵人（最重要的贵人星）

  以日干查：
  ┌────┬─────────────────────────────────┐
  │日干│天乙贵人地支                       │
  ├────┼─────────────────────────────────┤
  │甲戊│丑 未                              │
  │乙己│子 申                              │
  │丙丁│亥 酉                              │
  │庚辛│午 寅                              │
  │壬癸│巳 卯                              │
  └────┴─────────────────────────────────┘

  天乙贵人：逢凶化吉，得贵人相助，遇难呈祥

▶ 文昌贵人（学业、才华）

  以日干查：
  甲→巳  乙→午  丙→申  丁→酉
  戊→申  己→酉  庚→亥  辛→子
  壬→寅  癸→卯

▶ 月德贵人

  以月支查：
  寅午戌月 → 丙
  申子辰月 → 壬
  亥卯未月 → 甲
  巳酉丑月 → 庚

▶ 天德贵人

  以月支查：
  正月→丁  二月→申  三月→壬  四月→辛
  五月→亥  六月→甲  七月→癸  八月→寅
  九月→丙  十月→乙  十一月→巳  十二月→庚

▶ 驿马星（主动、出行、变动）

  以年支或日支三合局对冲之支：
  申子辰 → 驿马在寅
  寅午戌 → 驿马在申
  亥卯未 → 驿马在巳
  巳酉丑 → 驿马在亥

▶ 桃花（咸池）（人缘、情感）

  以年支或日支三合局之败地（第二字）：
  申子辰 → 桃花在酉
  寅午戌 → 桃花在卯
  亥卯未 → 桃花在子
  巳酉丑 → 桃花在午

【凶煞】

▶ 羊刃（阳刃）（主凶险、争斗）

  以日干查：
  甲→卯  丙→午  戊→午  庚→酉  壬→子
  （阴干无羊刃，或以阴干对应位查）

▶ 孤辰寡宿（主孤独、情感薄弱）

  以年支查：
  寅卯辰年 → 孤辰巳 寡宿丑
  巳午未年 → 孤辰申 寡宿辰
  申酉戌年 → 孤辰亥 寡宿未
  亥子丑年 → 孤辰寅 寡宿戌

▶ 华盖（主孤高、宗教、艺术）

  以年支三合局之墓库：
  申子辰 → 华盖在辰
  寅午戌 → 华盖在戌
  亥卯未 → 华盖在未
  巳酉丑 → 华盖在丑

▶ 劫煞（主破财、盗贼）

  以年支三合局旺支对冲之前一位：
  申子辰 → 劫煞在巳
  寅午戌 → 劫煞在亥
  亥卯未 → 劫煞在申
  巳酉丑 → 劫煞在寅

▶ 亡神（主耗散、破损）

  以年支三合局旺支对冲之后一位：
  申子辰 → 亡神在寅
  寅午戌 → 亡神在申
  亥卯未 → 亡神在巳
  巳酉丑 → 亡神在亥

【神煞使用原则】

1. 神煞是辅助工具，以五行生克为主，神煞为辅
2. 吉神得地（临旺、临贵人）则力量倍增
3. 凶煞遇合化、生助用神则力量减弱
4. 同一八字中神煞叠加，则效力加强
5. 流年大运触动神煞时，当年相关事项应验
