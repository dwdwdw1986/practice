【命理分析基本流程】

  1. 排盘
     → 根据出生年月日时，排出四柱（年柱、月柱、日柱、时柱）
     → 确定每柱天干地支

  2. 定阴阳
     → 判断年干阴阳（用于大运顺逆）
     → 日元（日干）阴阳

  3. 论五行强弱
     → 以月令为核心，判断日元旺衰
     → 统计各五行力量分布

  4. 定格局
     → 月令藏干透干定格
     → 判断是否成立特殊格局

  5. 取用神
     → 日元强弱决定用神方向
     → 确定喜用神与忌仇神

  6. 排大运
     → 顺/逆排，计算起运年龄
     → 分析每步大运吉凶

  7. 看流年
     → 流年与命局大运三者配合
     → 精确到年份事件推断

  8. 查神煞
     → 辅助参考，丰富分析维度
