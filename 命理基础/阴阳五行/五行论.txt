【五行生克关系】

▶ 相生（生助，顺）：
  木 → 火 → 土 → 金 → 水 → 木（循环）

  木生火：木燃烧生火
  火生土：火烧成灰化为土
  土生金：土中藏金矿
  金生水：金属遇冷凝结水珠
  水生木：水滋润木生长

▶ 相克（制约，逆）：
  木 → 土 → 水 → 火 → 金 → 木（循环）

  木克土：木根穿透土壤
  土克水：土坝堤防水
  水克火：水浇灭火
  火克金：火熔化金属
  金克木：金属刀斧砍木

【五行旺衰（月令）】

  月令是判断五行旺衰的核心依据。

  ┌────┬──────────────────────────────┐
  │月令│ 旺 → 相 → 休 → 囚 → 死    │
  ├────┼──────────────────────────────┤
  │春  │木旺 火相 水休 金囚 土死     │
  │夏  │火旺 土相 木休 水囚 金死     │
  │季月│土旺 金相 火休 木囚 水死     │
  │秋  │金旺 水相 土休 火囚 木死     │
  │冬  │水旺 木相 金休 土囚 火死     │
  └────┴──────────────────────────────┘

  旺 > 相 > 休 > 囚 > 死（力量递减）

【五行在八字中的十神】

以日元五行为我，其他五行定十神：

  同我（比劫）：
    同性 → 比肩（独立、竞争）
    异性 → 劫财（夺财、合作）

  我生（食伤）：
    同性 → 食神（享受、才艺）
    异性 → 伤官（聪慧、叛逆）

  我克（财）：
    同性 → 偏财（意外之财、父）
    异性 → 正财（稳定收入、妻）

  克我（官杀）：
    同性 → 七杀（压力、男命子）
    异性 → 正官（规矩、官职）

  生我（印）：
    同性 → 偏印（枭神、特殊技能）
    异性 → 正印（学历、母）
